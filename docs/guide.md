### 一般功能

Bot 的各种实用性功能。

| 功能名称 | 使用方法 |
| ---- | ---- |
| bot AI助手 | **/bot助手** [有关bot功能的疑问] |
| 测试 Bot 是否在线 | @testpilot **/ping** |
| 获取帮助 | **/actualhelp** |
| 生成或识别二维码 | **/qrcode** [要转换为二维码的文本 或 要识别的二维码图片] |
| 获取 xkcd 漫画 | **/xkcd** [图片号，不填写则为随机] |
| Markdown 渲染 | **/rendermd** [Markdown 源文本] |
| 网站导航 | **/sites**<br>[可选参数：wzq（Bot 作者个人站）<br>aira（音 MAD 维基、艾拉软件库）<br>yzm（音之墨）<br>pt（帕斯镇）<br>otomad（音 MADer 网站收集）] |

### 留言墙

将你发送的消息投放到 <a href="/cast" class="noroute">testpilot 留言墙</a>。<br>
任何访问留言墙网页的人都能看到你投放的消息。（公 屏）

| 功能名称 | 使用方法 |
| ---- | ---- |
| 投放消息到留言墙 | **/cast** [要投放的消息内容] |
| 匿名投放消息到留言墙 | **/anocast** [要投放的消息内容] |

### 管理员功能

向 Bot 或作者 QQ 号私聊即可申请管理员权限。<br>
申请到 Bot 的管理员权限后，可使用以下功能：

| 功能名称 | 使用方法 |
| ---- | ---- |
| 复读 CQ 码 | **/echocq** [要复读的CQ码] |
| 生成一张网页截屏 | **/webss** [网址] |
| 将群聊投放到留言墙 | **/castgroup** [要投放的群聊号，填0为禁用] |
| 查看成就触发记录 | **/askachi** |
| 向 Bot 所在的所有群聊发送消息 | **/broadcast** [消息内容] |
| 清除 AI 对话上下文 | **/reds** |
| 更改 AI 对话初始语句 | **/dssetup** [提示词] |
| 更改 AI 对话次数上限 | **/setdscount** [次数] |
| 查看功能列表 | **/fealist** |
| 启用某个功能 | **/enable** [功能名称] |
| 禁用某个功能 | **/disable** [功能名称] |
| 导入功能列表 | **/import** [功能列表 json] |
| 启用功能预设 | **/preset** [预设名] |
| 查看管理员列表 | **/adminlist** |
| 重载 Bot | **/reload** |
| 查看 Bot 运行日志 | **/viewlog** |
